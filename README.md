# Stock Monitor 股票监控工具

Stock Monitor 是基于 Python 和 Streamlit 的市场监控与信息展示项目，包含行情读取、监控任务编排、持仓状态展示和通知发送等模块。本仓库为脱敏后的公开版本，主要用于展示工程结构与实现方式，不包含完整的私人策略配置。

## 主要模块

| 模块 | 说明 |
| --- | --- |
| 可视化面板 | 使用 Streamlit 展示监控结果、市场信息和持仓状态 |
| 任务调度 | 组织定时扫描及相关监控流程 |
| 行情接入 | 提供行情数据读取和数据处理辅助代码 |
| 监控视图 | 包含动量、风险、回撤区域及市场情绪等视图相关代码 |
| 状态管理 | 管理配置、运行状态及持仓记录的读写 |
| 通知模块 | 提供消息组织和通知发送接口 |

## 目录结构


## 技术栈与环境

项目使用 Python、Streamlit、Pandas、NumPy 和 APScheduler，并包含 yfinance、Futu API 等行情接入依赖。Python 版本要求和依赖以 `pyproject.toml` 为准。

使用 uv 安装依赖：

```bash
uv sync
```

界面与调度入口分别为：

```bash
uv run streamlit run stock-monitor/app.py
uv run python stock-monitor/main.py
```

以上命令仅说明程序入口，不代表公开版本可以直接完成监控。实际运行依赖自行提供的配置、数据与服务连接；部分策略模块仅保留接口或占位实现，未经补全和验证可能无法正常运行。

## 公开范围与隐私边界

公开代码不提供具体的策略窗口、阈值、评分公式、排序参数和仓位规则，也不分发私人标的清单、持仓记录、运行日志、行情缓存、通知密钥或账户信息。部分默认配置已置空，部分私有计算实现已替换为占位接口；这些占位值不构成策略建议。

私人运行配置应保存在仓库外，通过环境变量或独立配置目录管理。请勿将 `.env`、账户凭据、运行数据及含有私人参数的文件提交到公开仓库。

`stock-monitor/private_rules.py` 提供显式配置和计算接口，不附带私人实现，也不会自动加载外部脚本。相关计算缺少配置时会抛出 `PrivateConfigurationRequired`，而不是使用猜测的窗口、阈值或公式。通用均线计算、行情读取、缓存、状态读写、调度和展示代码仍保留；字段名称及模块结构仍可能反映策略类别，不应将公开代码理解为完全隐藏策略方向。
